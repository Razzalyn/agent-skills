# agent-skills

Agent Skills for Trove. Each skill assumes the [Trove MCP](https://thetrove.io/api/mcp) is connected; Trove's own MCP server also publishes each one as a prompt, so Claude Desktop, Cursor and scheduled tasks can run them without installing the file.

| Skill | Use it when |
|---|---|
| [artifact-ideas](artifact-ideas/SKILL.md) | You want help remembering what's worth capturing — in a chat, or every week from a scheduled task. |
| [artifact-from-source](artifact-from-source/SKILL.md) | You have a specific thing in hand (a PR, a doc, a deck, meeting notes) and want it turned into a draft. |
